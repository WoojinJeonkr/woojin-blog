## 1. Problem

주차장에 차량이 여러 대 입차하고 출차하였다.

각 차량의 주차 시간이 주어졌을 때, 차량별 주차 요금을 계산하여 **전체 주차 요금**을 구하는 프로그램을 작성하시오.

주차 요금은 다음과 같이 계산한다.

- 기본 주차 시간은 `30분`이다.
- 기본 요금은 `1,000원`이다.
- 기본 시간을 초과하면 초과한 `10분`마다 `500원`이 추가된다.
- 10분 미만의 초과 시간도 10분으로 계산한다.

### 입력

첫 번째 줄에 주차한 차량의 수 `N`이 주어진다.

두 번째 줄에 각 차량의 주차 시간이 분 단위로 주어진다.

### 출력

모든 차량의 주차 요금을 합한 **전체 주차 요금**을 출력한다.

### 제한사항

- `1 <= N <= 100,000`
- `1 <= ParkingTime <= 1,000`
- 모든 주차 시간은 정수이다.

## 2. Input example

### Example 1

```text
4
20 30 45 70
```

### Example 2

```text
5
35 50 80 100 25
```

## 3. Output example

### 3.1. Example 1

```text
5500
```

### 3.2. Example 2

```text
10500
```

## 4. Explanation

### 4.1. Example 1

각 차량의 주차 요금은 다음과 같다.

- 20분: 기본 요금 `1,000원`
- 30분: 기본 요금 `1,000원`
- 45분: 15분 초과 → `1,000 + 500 × 2 = 2,000원`
- 70분: 40분 초과 → `1,000 + 500 × 4 = 3,000원`

따라서 전체 주차 요금은

`1,000 + 1,000 + 2,000 + 3,000 = 7,000원`

이다.

### 4.2. Example 2

각 차량의 주차 요금은 다음과 같다.

- 35분: 5분 초과 → `1,500원`
- 50분: 20분 초과 → `2,000원`
- 80분: 50분 초과 → `3,500원`
- 100분: 70분 초과 → `4,500원`
- 25분: 기본 요금 → `1,000원`

따라서 전체 주차 요금은

`1,500 + 2,000 + 3,500 + 4,500 + 1,000 = 12,500원`

이다.

## 5. Answer

```python
N = int(input())
parking_times = list(map(int, input().split()))

total_fee = 0

for time in parking_times:
    fee = 1000

    if time > 30:
        extra_time = time - 30
        extra_units = (extra_time + 9) // 10
        fee += extra_units * 500

    total_fee += fee

print(total_fee)
```
