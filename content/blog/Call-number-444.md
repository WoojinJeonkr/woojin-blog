## 1. Problem

어느 날 노트북을 사용하던 중 알 수 없는 전화가 걸려왔습니다.

화면에 표시된 발신번호는 신기하게도 `444`와 관련된 번호였습니다.

주인공은 `444`라는 숫자를 특별하게 생각하기 때문에, 전화번호에 `4`가 몇 번 등장하는지 세어보기로 했습니다.

전화번호는 숫자로만 이루어진 문자열로 주어집니다.

전화번호에서 숫자 `4`가 총 몇 번 등장하는지 구하는 프로그램을 작성하세요.

단, 전화번호의 길이가 매우 길 수 있으므로 정수로 변환하지 않고 문자열로 처리해야 합니다.

### 입력

첫 번째 줄에 전화번호의 개수 `PhoneNumberCount`가 주어집니다.

다음 `PhoneNumberCount`개의 줄에 전화번호가 하나씩 주어집니다.

각 전화번호는 숫자로만 이루어진 문자열입니다.

### 출력

각 전화번호에 포함된 숫자 `4`의 개수를 한 줄에 하나씩 출력합니다.

### 제한사항

- `1 ≤ PhoneNumberCount ≤ 100,000`
- `1 ≤ 전화번호의 길이 ≤ 100`
- 전화번호는 숫자로만 이루어져 있습니다.
- 각 전화번호는 `0`으로 시작할 수도 있습니다.

## 2. Input example

### Example 1

```text
5
444
123444
40404
987654321
111222333
```

### Example 2

```text
4
44444444
1234567890
404
444012444
```

## 3. Output example

### 3.1. Example 1

```text
3
3
3
1
0
```

### 3.2. Example 2

```text
8
1
2
6
```

## 4. Explanation

### 4.1. Example 1

첫 번째 전화번호는 다음과 같습니다.

```text
444
```

숫자 `4`가 3번 등장하므로 `3`을 출력합니다.

두 번째 전화번호는:

```text
123444
```

마지막 세 자리가 모두 `4`이므로 `3`을 출력합니다.

세 번째 전화번호는:

```text
40404
```

숫자 `4`가 세 번 등장하므로 `3`을 출력합니다.

네 번째 전화번호:

```text
987654321
```

에서는 숫자 `4`가 한 번 등장하므로 `1`을 출력합니다.

마지막 전화번호에는 `4`가 존재하지 않으므로 `0`을 출력합니다.

### 4.2. Example 2

첫 번째 전화번호는 `44444444`이므로 숫자 `4`가 총 8번 등장합니다.

두 번째 전화번호 `1234567890`에는 숫자 `4`가 한 번만 등장합니다.

세 번째 전화번호 `404`에는 `4`가 두 번 등장합니다.

마지막 전화번호 `444012444`에는 앞쪽에 `4`가 세 번, 뒤쪽에 `4`가 세 번 등장하므로 총 6번입니다.

## 5. Answer

```python
import sys

input = sys.stdin.readline

phone_number_count = int(input())

for _ in range(phone_number_count):
    phone_number = input().strip()

    call_number_count = phone_number.count("4")

    print(call_number_count)
```
