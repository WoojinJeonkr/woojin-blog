## 1. Problem

숫자로 구성된 데이터의 오류를 간단하게 확인하기 위해 체크섬을 계산하는 프로그램을 작성하시오.

체크섬은 입력된 숫자의 각 자릿수에 가중치를 곱한 뒤 모두 더하여 계산한다.

계산 규칙은 다음과 같다.

1. 입력된 숫자를 왼쪽부터 한 자리씩 분리한다.
2. 첫 번째 숫자에는 가중치 1을 곱한다.
3. 두 번째 숫자에는 가중치 2를 곱한다.
4. 세 번째 숫자에는 가중치 3을 곱한다.
5. 이후 숫자도 같은 방식으로 가중치를 1씩 증가시킨다.
6. 모든 곱셈 결과를 더한 값을 11로 나눈 나머지를 체크섬으로 사용한다.

입력된 숫자와 계산된 체크섬을 출력하시오.

### 입력

하나의 줄에 숫자로만 구성된 문자열이 주어진다.

### 출력

첫 번째 줄에는 입력된 숫자를 출력한다.

두 번째 줄에는 계산된 체크섬을 출력한다.

### 제한사항

- 입력 문자열의 길이는 1 이상 20 이하이다.
- 입력 문자열은 0부터 9까지의 숫자로만 구성된다.
- 입력 문자열의 맨 앞자리에 0이 올 수 있다.

## 2. Input example

### Example 1

```text
1234
```

### Example 2

```text
50721
```

## 3. Output example

### 3.1. Example 1

```text
1234
8
```

### 3.2. Example 2

```text
50721
6
```

## 4. Explanation

### 4.1. Example 1

입력된 숫자는 `1234`이다.

각 자릿수에 순서대로 가중치를 곱한다.

- 1 × 1 = 1
- 2 × 2 = 4
- 3 × 3 = 9
- 4 × 4 = 16

모든 결과를 더하면 30이다.

30을 11로 나눈 나머지는 8이므로 체크섬은 8이다.

### 4.2. Example 2

입력된 숫자는 `50721`이다.

각 자릿수에 순서대로 가중치를 곱한다.

- 5 × 1 = 5
- 0 × 2 = 0
- 7 × 3 = 21
- 2 × 4 = 8
- 1 × 5 = 5

모든 결과를 더하면 39이다.

39를 11로 나눈 나머지는 6이므로 체크섬은 6이다.

## 5. Answer

```python
number = input().strip()

total = 0

for index, digit in enumerate(number):
    weight = index + 1
    total += int(digit) * weight

checksum = total % 11

results = [
    number,
    str(checksum)
]

print("\n".join(results))
```
