## 1. Problem

재활용 센터에서는 수거한 폐기물을 종류별로 분류하고 무게를 기록한다.

폐기물은 다음 네 가지 종류로 구분한다.

- `1`: 플라스틱
- `2`: 종이
- `3`: 유리
- `4`: 금속

각 폐기물의 종류와 무게가 주어졌을 때, 종류별 수거량과 전체 수거 현황을 계산하는 프로그램을 작성하시오.

다음 정보를 출력한다.

- 전체 폐기물의 무게
- 플라스틱 수거량
- 종이 수거량
- 유리 수거량
- 금속 수거량
- 가장 무겁게 수거된 폐기물 종류

가장 무겁게 수거된 종류가 여러 개라면 플라스틱, 종이, 유리, 금속 순서로 먼저 나오는 종류를 출력한다.

### 입력

첫째 줄에 폐기물의 개수 \(N\)이 주어진다.

다음 \(N\)개의 줄에는 폐기물의 종류 \(T\)와 무게 \(W\)가 공백으로 구분되어 주어진다.

### 출력

첫째 줄에 전체 폐기물의 무게를 출력한다.

둘째 줄부터 다섯째 줄까지 플라스틱, 종이, 유리, 금속의 수거량을 순서대로 한 줄씩 출력한다.

여섯째 줄에 가장 무겁게 수거된 폐기물 종류를 출력한다.

### 제한사항

- \(1 \leq N \leq 1000\)
- \(T\)는 1, 2, 3, 4 중 하나이다.
- \(1 \leq W \leq 10000\)
- \(W\)는 폐기물 하나의 무게(g)이다.

## 2. Input example

### Example 1

```text
6
1 500
2 1200
3 800
4 1500
1 700
2 300
```

### Example 2

```text
5
1 1000
2 2000
3 2000
4 500
1 500
```

## 3. Output example

### 3.1. Example 1

```text
5000
1200
1500
800
1500
종이
```

### 3.2. Example 2

```text
6000
1500
2000
2000
500
종이
```

## 4. Explanation

### 4.1. Example 1

폐기물 종류별 수거량은 다음과 같다.

- 플라스틱: \(500 + 700 = 1200\)g
- 종이: \(1200 + 300 = 1500\)g
- 유리: \(800\)g
- 금속: \(1500\)g

전체 폐기물의 무게는 \(1200 + 1500 + 800 + 1500 = 5000\)g이다.

종이와 금속이 각각 1500g으로 가장 많이 수거되었다. 두 종류의 수거량이 같으므로 우선순위가 더 높은 종이를 출력한다.

### 4.2. Example 2

폐기물 종류별 수거량은 다음과 같다.

- 플라스틱: \(1000 + 500 = 1500\)g
- 종이: \(2000\)g
- 유리: \(2000\)g
- 금속: \(500\)g

전체 폐기물의 무게는 6000g이다.

종이와 유리가 각각 2000g으로 가장 많이 수거되었다. 우선순위가 더 높은 종이를 출력한다.

## 5. Answer

```python
n = int(input())

weights = [0, 0, 0, 0, 0]
names = {
    1: "플라스틱",
    2: "종이",
    3: "유리",
    4: "금속"
}

for _ in range(n):
    t, w = map(int, input().split())
    weights[t] += w

total = sum(weights[1:])
max_weight = max(weights[1:])
best_type = weights[1:].index(max_weight) + 1

print(total)

for i in range(1, 5):
    print(weights[i])

print(names[best_type])
```
