## 1. Problem

한 가정에서 한 달 동안 사용한 전력량을 기록하고 있다.

전력 사용량에 따라 전기 요금을 계산하는 프로그램을 작성하시오.

전기 요금은 다음과 같이 계산한다.

- 처음 100kWh까지는 1kWh당 100원이다.
- 100kWh 초과 200kWh 이하의 사용량은 1kWh당 150원이다.
- 200kWh를 초과하는 사용량은 1kWh당 200원이다.

각 구간에는 해당 구간의 사용량만큼 요금을 적용한다.

### 입력

첫 번째 줄에 전력 사용량을 기록한 가정의 수 `N`이 주어진다.

다음 `N`개의 줄에 각 가정의 월간 전력 사용량이 kWh 단위로 주어진다.

### 출력

각 가정의 전기 요금을 한 줄에 하나씩 입력된 순서대로 출력한다.

### 제한사항

- `1 <= N <= 100,000`
- `0 <= ElectricityUsage <= 10,000`
- 모든 입력값은 정수이다.

## 2. Input example

### Example 1

```text
3
80
150
250
```

### Example 2

```text
4
0
100
200
350
```

## 3. Output example

### 3.1. Example 1

```text
8000

```

### 3.2. Example 2

```text
0
10000
25000

```

## 4. Explanation

### 4.1. Example 1

첫 번째 가정은 80kWh를 사용했다.

`80 × 100 = 8,000`

따라서 전기 요금은 8,000원이다.

두 번째 가정은 150kWh를 사용했다.

- 처음 100kWh: `100 × 100 = 10,000원`
- 다음 50kWh: `50 × 150 = 7,500원`

전체 요금은 `10,000 + 7,500 = 17,500원`이다.

세 번째 가정은 250kWh를 사용했다.

- 처음 100kWh: `100 × 100 = 10,000원`
- 다음 100kWh: `100 × 150 = 15,000원`
- 나머지 50kWh: `50 × 200 = 10,000원`

전체 요금은 `10,000 + 15,000 + 10,000 = 35,000원`이다.

### 4.2. Example 2

첫 번째 가정은 전력을 사용하지 않았으므로 요금은 0원이다.

두 번째 가정은 100kWh를 사용했으므로 요금은 10,000원이다.

세 번째 가정은 200kWh를 사용했다.

`100 × 100 + 100 × 150 = 25,000`

따라서 요금은 25,000원이다.

네 번째 가정은 350kWh를 사용했다.

- 처음 100kWh: 10,000원
- 다음 100kWh: 15,000원
- 나머지 150kWh: 30,000원

전체 요금은 `10,000 + 15,000 + 30,000 = 55,000원`이다.

## 5. Answer

```python
N = int(input())

for _ in range(N):
    usage = int(input())
    bill = 0

    first_section = min(usage, 100)
    bill += first_section * 100

    second_section = min(max(usage - 100, 0), 100)
    bill += second_section * 150

    third_section = max(usage - 200, 0)
    bill += third_section * 200

    print(bill)
```
