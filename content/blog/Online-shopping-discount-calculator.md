## 1. Problem

온라인 쇼핑몰에서는 상품의 가격과 구매 수량에 따라 할인 쿠폰을 적용한다.

여러 상품의 가격과 수량이 주어졌을 때, 각 상품의 할인 전 금액과 할인 후 금액을 계산하는 프로그램을 작성하시오.

할인 규칙은 다음과 같다.

- 상품의 가격과 수량을 곱하여 할인 전 금액을 계산한다.
- 할인 전 금액이 50,000원 이상이면 10% 할인한다.
- 할인 전 금액이 30,000원 이상 50,000원 미만이면 5% 할인한다.
- 할인 전 금액이 30,000원 미만이면 할인하지 않는다.
- 할인 후 금액은 소수점 이하를 버리고 정수로 출력한다.

### 입력

첫째 줄에 상품의 개수 \(N\)이 주어진다.

다음 \(N\)개의 줄에는 각 상품의 가격 \(P\)와 구매 수량 \(Q\)가 공백으로 구분되어 주어진다.

### 출력

각 상품에 대해 할인 전 금액과 할인 후 금액을 공백으로 구분하여 한 줄에 출력한다.

### 제한사항

- \(1 \leq N \leq 100\)
- \(1 \leq P \leq 1,000,000\)
- \(1 \leq Q \leq 100\)
- \(P\)는 상품 하나의 가격이며, \(Q\)는 구매 수량이다.

## 2. Input example

### Example 1

```text
4
10000 2

```

### Example 2

```text
3

```

## 3. Output example

### 3.1. Example 1

```text
20000 20000
40000 38000
60000 54000
60000 54000
```

### 3.2. Example 2

```text
15000 15000
30000 28500
50000 45000
```

## 4. Explanation

### 4.1. Example 1

첫 번째 상품은 10,000원짜리 상품을 2개 구매하므로 할인 전 금액은 20,000원이다. 30,000원 미만이므로 할인되지 않는다.

두 번째 상품은 20,000원짜리 상품을 2개 구매하므로 할인 전 금액은 40,000원이다. 5% 할인하여 38,000원이 된다.

세 번째 상품은 30,000원짜리 상품을 2개 구매하므로 할인 전 금액은 60,000원이다. 10% 할인하여 54,000원이 된다.

네 번째 상품은 60,000원짜리 상품을 1개 구매하므로 할인 전 금액은 60,000원이다. 10% 할인하여 54,000원이 된다.

### 4.2. Example 2

첫 번째 상품의 할인 전 금액은 15,000원이므로 할인되지 않는다.

두 번째 상품의 할인 전 금액은 30,000원이므로 5% 할인하여 28,500원이 된다.

세 번째 상품의 할인 전 금액은 50,000원이므로 10% 할인하여 45,000원이 된다.

## 5. Answer

```python
n = int(input())

for _ in range(n):
    price, quantity = map(int, input().split())
    total = price * quantity

    if total >= 50000:
        discounted = int(total * 0.9)
    elif total >= 30000:
        discounted = int(total * 0.95)
    else:
        discounted = total

    print(total, discounted)
```
