## 1. Problem

컴퓨터 네트워크에서 일정한 간격으로 전송된 데이터의 크기를 기록하고 있다.

각 시간대에 전송된 데이터의 크기가 주어졌을 때, 전체 데이터 전송량과 **가장 많은 데이터가 전송된 시간대의 데이터 크기**를 계산하는 프로그램을 작성하시오.

### 입력

첫 번째 줄에 데이터를 측정한 시간대의 수 `N`이 주어진다.

두 번째 줄에 각 시간대에 전송된 데이터의 크기가 순서대로 주어진다.

### 출력

첫 번째 줄에 전체 데이터 전송량을 출력한다.

두 번째 줄에 한 시간대에서 전송된 데이터의 최대 크기를 출력한다.

### 제한사항

- `1 <= N <= 100,000`
- 각 시간대의 데이터 크기는 `0 <= Data <= 1,000,000`
- 모든 데이터 크기는 정수이다.

## 2. Input example

### Example 1

```text
5
120 250 180 300 150
```

### Example 2

```text
6
500 120 350 200 450 180
```

## 3. Output example

### 3.1. Example 1

```text
1000
300
```

### 3.2. Example 2

```text
1800
500
```

## 4. Explanation

### 4.1. Example 1

각 시간대의 데이터 전송량은 다음과 같다.

`120, 250, 180, 300, 150`

전체 데이터 전송량은

`120 + 250 + 180 + 300 + 150 = 1000`

이다.

가장 많은 데이터가 전송된 시간대의 크기는 `300`이다.

### 4.2. Example 2

각 시간대의 데이터 전송량은 다음과 같다.

`500, 120, 350, 200, 450, 180`

전체 데이터 전송량은

`500 + 120 + 350 + 200 + 450 + 180 = 1800`

이다.

가장 많은 데이터가 전송된 시간대의 크기는 `500`이다.

## 5. Answer

```python
N = int(input())
data = list(map(int, input().split()))

total_data = sum(data)
maximum_data = max(data)

print(total_data)
print(maximum_data)
```
